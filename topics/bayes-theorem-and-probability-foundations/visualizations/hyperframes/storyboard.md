# Теорема Байеса: условная вероятность → полная вероятность → posterior — сториборд

Клип `assets/visualizations/bayes-theorem-total-probability.{mp4,gif}`, 42 с, 1920×1080, без звука.
Одна идея на сцену; каждая сцена — вопрос в заголовке, 3–4 подписи внизу, в конце ключевая идея.
Факты сверены с `../../README.md` (разделы «Условная вероятность» → «Пример», «Формула полной вероятности»,
«Теорема Байеса», «Интуиция: почему теорема Байеса работает» → «Пример: медицинский тест»).
Клип дополняет статические картинки README (`assets/images/venn_conditional.png`, `venn_partition.png`):
вместо диаграмм Венна — клетки-исходы, площадь которых равна вероятности, и один сквозной числовой пример.

| # | Время | Вопрос | Что на экране | Подписи (по порядку) |
|---|---|---|---|---|
| 1 | 0–13 с | Что такое условная вероятность P(A\|B)? | Шесть клеток-исходов кубика Ω = {1,…,6}; клетка 6 получает оранжевую рамку (A); чётные клетки подсвечиваются синим (B), нечётные гаснут, три оставшиеся растягиваются на всё пространство — «Ω сужается до B»; карточки «Условная вероятность» P(A\|B) = P(A∩B)/P(B) и «Кубик» с числами | Ω = {1,…,6}, A = «выпало 6»: P(A) = 1/6 · узнали B = «чётное»: сужаем Ω до B = {2, 4, 6} · P(A\|B) = (1/6)/(1/2) = 1/3 — доля A внутри B |
| 2 | 13–28 с | Как найти P(+), если Ω разбито на гипотезы? | Сетка 10×10 «100 человек»: 99 синих (здоров, H₂) и 1 оранжевая (болен, H₁); тест ставит красный «+» на больного и на 5 здоровых; легенда P(H₁) = 0.01, P(H₂) = 0.99, P(+\|H₁) = 0.99, P(+\|H₂) = 0.05; карточки «Разбиение Ω на гипотезы» и «Формула полной вероятности» с суммой 0.0099 + 0.0495 = 0.0594 | разбиваем Ω: H₁ «болен» 1%, H₂ «здоров» 99% · чувствительность 99%, специфичность 95% → «+» у 5% здоровых · P(+) = Σ P(+\|Hᵢ)·P(Hᵢ) = 0.0594 · большая часть плюсов — от здоровых |
| 3 | 28–42 с | Как тест «+» обновляет prior → posterior? | Сетка гаснет, шесть клеток с «+» выстраиваются в ряд и увеличиваются — Ω сужено до «+»; подпись «1 из 6 болен → P(болен\|+) = 1/6 ≈ 0.167»; карточка «Теорема Байеса» 0.99·0.01/0.0594 ≈ 0.167; столбики prior 0.01 → posterior 0.167 | сужаем Ω до события «+» · Байес = та же условная вероятность: 0.0099/0.0594 ≈ 0.167 · **ключевая идея**: Posterior ∝ Likelihood × Prior; «+» поднял веру с 1% до 16.7%, но большинство «+» — ложноположительные |

Числа (все из README темы): кубик — P(A) = 1/6, P(B) = 1/2, P(A∩B) = 1/6, P(A|B) = 1/3;
медицинский тест — P(болен) = 0.01, чувствительность P(+|болен) = 0.99, специфичность P(−|здоров) = 0.95
(⇒ P(+|здоров) = 0.05), P(+) = 0.99·0.01 + 0.05·0.99 = 0.0099 + 0.0495 = 0.0594, P(болен|+) = 0.0099/0.0594 ≈ 0.167 = 16.7 %.
Иллюстративно: сетка «на 100 человек» округляет 0.99 больного с «+» до 1 клетки и 4.95 здоровых с «+» до 5 клеток
(отношение 1/6 при этом точное: 0.0099/0.0594 = 1/6); позиции клеток с «+» заданы константами.
