## Числа

- Из README: G = 1 − Σ p_k², H = −Σ p_k log₂ p_k, IG = Impurity(S) − |S_L|/|S|·Impurity(S_L) − |S_R|/|S|·Impurity(S_R);
  пример p₁ = 0.8, p₂ = 0.2 → G = 1 − 0.68 = 0.32, H ≈ 0.72 бит; G_max = 1 − 1/K, H_max = log₂ K; CART — Gini и бинарные
  разбиения, ID3/C4.5 — энтропия; техники против переобучения: max_depth, min_samples_leaf, min_samples_split, pruning.
- Иллюстративная выборка (20 точек, 16 + 4) подобрана так, чтобы корень давал ровно p = (0.8, 0.2). Значения IG по Gini
  для порогов по x₁: t = 3 → 7/0 и 9/4, G_R = 0.426, IG = 0.043; t = 6 → 14/0 и 2/4, G_R = 4/9 ≈ 0.444,
  IG = 0.32 − 0.3·0.444 ≈ 0.187; t = 8 → 15/2 и 1/2, G_L = 0.208, G_R ≈ 0.444, IG ≈ 0.077.
  Второй порог x₂ ≤ 5 в правом узле даёт листья 2/0 и 0/4 (G = 0). Выброс и пороги 4.2 / 5.3 в цепочке переобучения — иллюстративно.

## Сборка

```bash
cd topics/decision-trees/visualizations/hyperframes
npx -y hyperframes@0.8.81 check                       # 0 ошибок, 0 предупреждений
npx -y hyperframes@0.8.81 snapshot --at 2,7,11,14,19,23,27,30,34,37,41
npx -y hyperframes@0.8.81 render --quality looks --output renders/decision-tree-gini-split.mp4
ffmpeg -i renders/decision-tree-gini-split.mp4 -c:v libx264 -preset slow -crf 28 -tune animation -pix_fmt yuv420p -movflags +faststart ../../assets/visualizations/decision-tree-gini-split.mp4
uv run python ../../../../scripts/viz/mp4_to_gif.py ../../assets/visualizations/decision-tree-gini-split.mp4 -o ../../assets/visualizations/decision-tree-gini-split.gif
```
