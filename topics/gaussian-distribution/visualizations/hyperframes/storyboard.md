# Гауссиана: PDF, правило 68-95-99.7 и многомерный случай — сториборд

Клип `assets/visualizations/gaussian-pdf-and-multivariate.{mp4,gif}`, 43 с, 1920×1080, без звука.
Одна идея на сцену; каждая сцена — вопрос в заголовке, 3–4 подписи внизу, в конце ключевая идея.
Факты сверены с `../../README.md` (разделы «Определение и Формула», «Свойства Гауссова Распределения», «Стандартное Нормальное
Распределение», «Многомерное Гауссово Распределение», «Применение в Машинном Обучении», «Связь с Diffusion Models»).
Клип дополняет статический график `assets/images/normal_pdf.png` движением: та же кривая как функция параметров.

| # | Время | Вопрос | Что на экране | Подписи (по порядку) |
|---|---|---|---|---|
| 1 | 0–14 с | Что задают μ и σ в гауссиане? | Оси x / p(x), кривая N(0, 1) рисуется; карточка с формулой p(x) = 1/(σ√(2π))·exp(−(x−μ)²/(2σ²)); пунктирный «призрак» N(0, 1); колокол едет по оси при μ = 0 → −2 → 2 → 0; затем растягивается/сжимается при σ = 1 → 0.5 → 2 (преобразование scaleX = σ, scaleY = 1/σ — точное); карточка «Параметры» с живыми μ, σ и пиком p(μ) = 0.399 → 0.798 → 0.199 | плотность — «колокол», центр μ, ширина σ, максимум 1/(σ√(2π)) · μ — среднее: колокол едет, форма не меняется · σ — разброс: малое σ → узкий высокий пик, большое → широкий низкий |
| 2 | 14–28 с | Сколько данных лежит в μ ± kσ? | Кривая с осью μ−3σ … μ+3σ; синяя площадь растёт от μ симметрично: ±σ → 68 %, ±2σ → 95 %, ±3σ → 99.7 %, карточка правила подсвечивает строки; подписи оси меняются на z = −3 … 3, карточка «Стандартизация и CDF» (z = (x−μ)/σ, p(z), Φ(z) = P(Z ≤ z)); зелёная площадь слева от бегущего z, мини-график Φ(z) с точкой и счётчик Φ(z) = 0.001 → 0.999 | правило 68–95–99.7 · стандартизация z = (x − μ)/σ → N(0, 1) · CDF Φ(z) — площадь слева от z, растёт от 0 до 1, Φ(0) = 0.5 по симметрии |
| 3 | 28–43 с | Как выглядит гауссиана в d измерениях? | Плоскость x₁x₂, окружности 1σ и 2σ (Σ = I) и 34 детерминированные точки (иллюстративно); карточки: формула p(x) для N(μ, Σ), Σ = I → Σ = diag(4, 1) (scaleX 2) → Σ = [[1, 0.5],[0.5, 1]] (полуоси √1.5, √0.5, поворот 45°); потом карточка «Почему гауссиана везде в ML»: ЦПТ, diffusion forward q(x_t \| x_{t−1}), VAE latent N(0, I), L2 = априор N(0, λ⁻¹I) | линии равной плотности — эллипсы, при Σ = I окружности · диагональная Σ — растяжение по осям без поворота · ковариация 0.5 — оси повёрнуты на 45°: Σ = масштаб + поворот · **ключевая идея**: гауссиана = сдвиг μ + масштаб/поворот Σ; ЦПТ, замкнутость относительно сумм и линейных преобразований — основа diffusion, VAE и регуляризации |

Числа и формулы (из README): p(x) = 1/(σ√(2π))·exp(−(x−μ)²/(2σ²)); p(μ) = 1/(σ√(2π)) → 0.399 / 0.798 / 0.199 при σ = 1 / 0.5 / 2;
наборы параметров (0, 1), (0, 0.5), (0, 2), (−2, 1), (2, 1) — из примера «Разные Параметры»; правило 68 / 95 / 99.7 %;
z = (x − μ)/σ, p(z) = 1/√(2π)·exp(−z²/2), Φ(z) = P(Z ≤ z) = ∫ p(t) dt; многомерная p(x) с (2π)^{d/2}|Σ|^{1/2} и (x−μ)ᵀΣ⁻¹(x−μ);
Σ = [[1, 0.5],[0.5, 1]] — из примера «Многомерное Распределение»; q(x_t | x_{t−1}) = N(x_t; √(1−β_t) x_{t−1}, β_t I), x_T ~ N(0, I);
VAE latent N(0, I); L2 ↔ N(0, λ⁻¹I). Вычислено по этим формулам: собственные числа Σ = [[1, 0.5],[0.5, 1]] — 1.5 и 0.5
(векторы (1, 1)/√2 и (1, −1)/√2 → поворот 45°), Σ = diag(4, 1) → σ₁ = 2, σ₂ = 1; значения Φ(z) на мини-графике — численно через erf.

## Сборка

npx -y hyperframes@0.8.81 check                       # 0 ошибок, 0 предупреждений
npx -y hyperframes@0.8.81 snapshot --at 3,7,12,17,21,26,31,36,41

ffmpeg -i renders/gaussian-pdf-and-multivariate.mp4 -c:v libx264 -preset slow -crf 28 -tune animation -pix_fmt yuv420p -movflags +faststart ../../assets/visualizations/gaussian-pdf-and-multivariate.mp4
uv run python ../../../../scripts/viz/mp4_to_gif.py ../../assets/visualizations/gaussian-pdf-and-multivariate.mp4 -o ../../assets/visualizations/gaussian-pdf-and-multivariate.gif
